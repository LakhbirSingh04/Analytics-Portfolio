# Sales Performance Dashboard

## Overview
Interactive Power BI dashboard analyzing sales and profit performance across multiple products and segments.

## Key Features
- 📊 Total Sales & Profit KPIs
- 📈 Sales trends and forecasting capabilities
- 🎯 Product performance analysis
- 📉 Segment-wise profit breakdown
- 🔍 Time-series analysis of product sales

## Tools Used
- Power BI Desktop
- DAX for custom measures
- Data modeling and visualization

## Key Insights
- Paseo is the best-selling product (33M in sales)
- Overall profit margin: 14.23%
- Government segment contributes highest profit (11.39M)
- Clear seasonal trends in sales performance
